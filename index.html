DepScan

Dependency Vulnerability Scanner for Claude Code

为什么开发者需要 DepScan？

在当今的软件供应链中，依赖漏洞是主要的安全风险之一。DepScan 帮助您:

  • 自动检测项目依赖中的已知漏洞
  • 支持多种生态系统：Node.js, Python, Rust, Go
  • 提供清晰的修复建议
  • 无缝集成到 Claude Code 工作流程

主要功能

多生态系统支持

自动检测并扫描 Node.js, Python, Rust 和 Go 项目的依赖漏洞

一键修复

使用 /dep-scan --fix 自动修复可修复的漏洞

清晰报告

以易读的文本或机器可解析的 JSON 格式输出扫描结果

Claude Code 原生集成

作为 Claude Code 插件直接工作，无需离开终端

如何使用

  1. 安装 Claude Code（如果尚未安装）： 
    curl -fsSL https://claude.ai/install.sh | bash
  2. 安装 DepScan 插件： 
    claude plugin install /path/to/dep-scan-plugin
  3. 在项目中运行扫描： 
    /dep-scan
